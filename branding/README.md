# Vesper Desk logos

Source artwork from Justin. Not bundled as-is; derived files:

| File | Used for |
| --- | --- |
| `vesper-desk-mark.png` | `build/icon.png` (512px): the Windows EXE, installer, and shortcut icon |
| `vesper-desk-logo-stacked.png` | `src/assets/vesper-desk-logo.png` (640px): Settings → Help |
| `vesper-desk-logo-horizontal.png` | Source only (landing site, store listings) |

The in-app chrome mark stays a transparent `currentColor` stroke version of the same V/A monogram
(`src/assets/vesper-mark.svg`, ~30px with the soft cyan glow). These PNGs sit on a black plate,
which the chrome must not show, and their metal shading does not read at 30px.
